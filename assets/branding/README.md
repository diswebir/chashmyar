# ChashmYar branding assets

[Project README](../../README.en.md) · [Development](../../docs/DEVELOPMENT.md) · [CI and release](../../docs/CI_AND_RELEASE.md)

## Source and usage

- [`chashmyar-logo-selected.png`](chashmyar-logo-selected.png) is the approved 2048 × 2048 raster artwork. It was created with AI assistance using the supplied black-and-white eye reference, then selected for this project. It is a PNG, not a vector master.
- [`asset-hashes.json`](asset-hashes.json) records SHA-256 hashes of the selected source and each generated asset. It detects accidental changes in CI; the manifest itself is not a digital signature.
- [`src-tauri/icons/`](../../src-tauri/icons/icon.png) contains the application PNGs and [`icon.ico`](../../src-tauri/icons/icon.ico). The ICO has 16, 24, 32, 48, 64, 128 and 256px frames.
- Tauri's default icon is used by the system tray. The 128px PNG is also used in the app header, and the 32px PNG is the browser favicon. Both READMEs use the 128px image.

The generator keeps the selected eye's silhouette, iris and highlight. It removes the off-white background and places the mark on a white rounded tile with a subtle outline and transparent corners. The white tile helps a dark mark remain visible on light and dark taskbars. Small sizes have been inspected as images; actual Windows Explorer, tray, taskbar and DPI rendering still require native testing.

## Validate without Python

From the repository root:

```sh
npm run test:branding
npm run test:docs
```

The first check reads the manifest, PNG dimensions/transparency and ICO frames and compares corresponding pixel data; it also checks Tauri/tray references. It uses Node's built-in libraries and does not build an executable. `npm run test:ui:all` additionally checks the loaded header and favicon in a browser/mock; it is not a native Windows test.

## Optional regeneration

Regeneration is **not** needed to build or publish the committed assets. The crop is calibrated specifically to the approved 2048px artwork. Do not replace the source or alter its crop without intentional review. With Python 3.10+ and Pillow 13.0.0, for example on Windows:

```powershell
python -m venv .venv
.\.venv\Scripts\python -m pip install Pillow==13.0.0
.\.venv\Scripts\python scripts/generate-icons.py --check
# Only after an intentional, reviewed change:
.\.venv\Scripts\python scripts/generate-icons.py
npm run test:branding
```

On Unix-like systems use `.venv/bin/python` instead. The generator updates all six PNG files, the ICO and the hash manifest. `--check` compares exact generated bytes; Pillow, zlib or platform differences can affect compression even when pixels appear identical. Investigate unexpected differences rather than silently accepting them. Review the resulting diff, the 16/32px frames, both UI themes and the native Windows taskbar/tray before release. The virtual environment is ignored by Git.
